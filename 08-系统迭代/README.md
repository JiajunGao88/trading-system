## 迭代流程

### 什么时候迭代系统？

1. **月度复盘后** → 根据统计数据调整参数
2. **连亏触发熔断后** → 深度审查系统规则
3. **发现新策略** → 纳入 Playbook 验证流程
4. **市场环境变化** → 调整风控参数
5. **积累 50 笔交易** → 全面系统评估

### 迭代步骤

1. **识别问题** → 数据说话，不是感觉
2. **提出假设** → 如果改 X，预期 Y 会改善
3. **小规模验证** → 纸上交易或 0.5R 仓位测试
4. **评估效果** → 至少 10 笔交易后评估
5. **正式纳入** → 通过验证后更新系统文档
6. **记录变更** → 在此文件更新版本号和变更日志

### 版本号规则
- **主版本号** (v2.0.0)：重大系统重构
- **次版本号** (v1.1.0)：新增策略或模块
- **修订号** (v1.0.1)：参数微调或模板修改
