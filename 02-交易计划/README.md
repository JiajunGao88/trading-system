## 计划状态说明

- **草案** → 初步想法，待完善
- **待触发** → 计划完成，等待价格到位
- **已触发** → 已入场，转入持仓跟踪 + 交易日志
- **已失效** → 条件不再成立，取消计划
- **已过期** → 超过有效期未触发

---

## 使用流程

1. 发现交易机会 → 用 `plan-template.md` 创建计划
2. 检查是否符合 Playbook 中的策略
3. 检查是否符合 `SYSTEM-RULES.md` 的所有规则
4. 确认市场环境适合（查看 `07-市场环境/`）
5. 设定有效期（通常 3-5 个交易日）
6. 等待触发 → 触发后填写交易日志
