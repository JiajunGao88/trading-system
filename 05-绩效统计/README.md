## 核心公式参考

```
胜率 = 盈利次数 ÷ 总交易次数 × 100%

期望值 = (胜率 × 平均盈利R) - (败率 × 平均亏损R)
  > 正数 = 系统有正期望值，长期能赚钱
  > 目标：> 0.3R

利润因子 = 总盈利金额 ÷ 总亏损金额
  > > 1.0 = 赚的比亏的多
  > 目标：> 1.5

盈亏比 = 平均盈利R ÷ |平均亏损R|
  > 目标：> 2.0

最大回撤 = (峰值 - 谷值) ÷ 峰值 × 100%
  > 红线：< 10%（账户级别），< 20%（极端情况）

R倍数 = (出场价 - 入场价) ÷ (入场价 - 止损价)
  > 正数 = 盈利，负数 = 亏损
  > -1R = 止损出场（正常亏损）
```
