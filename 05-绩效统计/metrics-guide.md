# 绩效指标指南

> 理解你的数据，才能改进你的交易。

---

## 核心指标详解

### 1. R 倍数 (R-Multiple)
**最重要的单笔交易度量**

R = 你在这笔交易中承担的风险单位。1R = 你设定的止损金额。

| R值 | 含义 | 评价 |
|-----|------|------|
| +3R | 赚了3倍风险金额 | 优秀交易 |
| +2R | 赚了2倍风险金额 | 好交易 |
| +1R | 赚了1倍风险金额 | 一般 |
| 0R | 不赚不亏（成本出场） | 保本 |
| -0.5R | 亏了半个风险单位 | 提前止损（可能是好决定） |
| -1R | 完整止损 | 正常亏损，纪律体现 |
| -1.5R | 超额亏损 | 问题！跳空或执行不力 |
| -2R+ | 重大亏损 | 严重问题，必须复盘 |

**为什么用 R 而不是百分比？**
因为 R 标准化了风险。一笔赚 5% 但冒了 3% 风险的交易（1.67R），不如一笔赚 3% 但只冒了 1% 风险的交易（3R）。

---

### 2. 期望值 (Expectancy)
**系统是否有正期望值的终极指标**

```
期望值 = (胜率 × 平均盈利R) - (败率 × |平均亏损R|)
```

| 期望值 | 含义 |
|--------|------|
| > 0.5R | 优秀系统 |
| 0.3-0.5R | 良好系统 |
| 0.1-0.3R | 可用但需优化 |
| 0-0.1R | 勉强盈亏平衡 |
| < 0R | 亏损系统，必须修正 |

**示例：**
- 胜率 45%，平均赢 2.5R，平均亏 1R
- 期望值 = (0.45 × 2.5) - (0.55 × 1.0) = 1.125 - 0.55 = **0.575R**
- 含义：每笔交易平均赚 0.575R，这是一个优秀系统

---

### 3. 利润因子 (Profit Factor)
**总盈利与总亏损的比率**

```
利润因子 = 总盈利金额 ÷ 总亏损金额
```

| 利润因子 | 含义 |
|---------|------|
| > 2.0 | 优秀 |
| 1.5-2.0 | 良好 |
| 1.2-1.5 | 可接受 |
| 1.0-1.2 | 勉强盈利，需改进 |
| < 1.0 | 亏损系统 |

---

### 4. 最大回撤 (Maximum Drawdown)
**从峰值到谷值的最大跌幅**

这是风险管理的核心指标。机构对此极度敏感。

| 回撤 | 回到峰值需要的涨幅 | 评价 |
|------|-------------------|------|
| -5% | +5.3% | 健康 |
| -10% | +11.1% | 警惕 |
| -20% | +25.0% | 危险 |
| -30% | +42.9% | 严重 |
| -50% | +100.0% | 灾难性 |

**我们的红线：最大回撤不超过 10%**

---

## 需要多少笔交易才能评估系统？

| 交易次数 | 置信度 | 可以做什么 |
|---------|--------|-----------|
| 10 笔 | 极低 | 仅发现明显问题 |
| 20 笔 | 低 | 初步判断策略方向 |
| 30 笔 | 中等 | 可以初步评级策略 |
| 50 笔 | 较高 | 统计数据开始有意义 |
| 100 笔 | 高 | 可以自信评估系统表现 |

**关键：前 30 笔交易用小仓位（0.5R），这是学费，不是赚钱阶段。**

## 常见交易者类型画像

| 类型 | 胜率 | 盈亏比 | 期望值 | 特征 |
|------|------|--------|--------|------|
| 高胜率型 | 65%+ | 1:1-1.5:1 | 0.3-0.5R | 精准入场，目标保守 |
| 高盈亏比型 | 35-45% | 3:1+ | 0.4-0.7R | 愿意多次小亏等大赢 |
| 均衡型 | 50% | 2:1 | 0.5R | 两者平衡，最稳定 |
| 散户典型 | 55% | 0.5:1 | -0.2R | 赢小亏大，长期亏损 |

**我们的目标：均衡型或高盈亏比型**
