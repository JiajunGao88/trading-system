### 新增持仓前检查
- [ ] 当前持仓数 < 5
- [ ] 组合热度 + 新仓风险 <= 6%
- [ ] 与现有持仓相关性低（不同板块）
- [ ] 有完整的交易计划

- [ ] 所有止损是否仍在有效技术位
