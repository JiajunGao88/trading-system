## 文件命名规范

每笔交易一个文件：`T[序号]-[标的]-[YYYYMMDD].md`

示例：
- `T001-OXY-20260316.md`
- `T002-NVDA-20260320.md`

---

## 使用说明

1. **入场时**：从 `trade-template.md` 复制，填写计划部分
2. **持仓中**：更新持仓状态和重要观察
3. **出场后**：填写结果部分、自我评分、复盘
4. **定期**：告诉我"更新统计"，我会汇总所有日志数据
